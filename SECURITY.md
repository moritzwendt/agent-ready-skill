# Security

agent-ready contains no executable code that runs in your repository. It is a set of instructions and templates that tell agents what to read and write. A problem in those instructions can still cause harm, for example if an agent is led to copy secrets into docs, delete files or act without asking.

## Reporting a problem

Please report security problems privately, not in a public issue:

1. Open the Security tab of this repository.
2. Choose "Report a vulnerability".
3. Describe the agent, the repository state and the steps that lead to the problem.

## Supported versions

Only the latest release gets fixes.
