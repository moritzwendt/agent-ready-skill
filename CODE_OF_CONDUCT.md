# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback, and keep discussions about the work. Harassment, insults and personal attacks are not tolerated in issues, pull requests or any other project space.

## Reporting

Report unacceptable behavior privately to the maintainer, [moritzwendt](https://github.com/moritzwendt) on GitHub. Reports are handled confidentially.

The maintainer may remove comments, issues or contributions that break these rules, and may block people from the project temporarily or permanently.
